# Sojib Tv Android App

## APK বানানোর ধাপ (GitHub দিয়ে, PC ছাড়া)

### ধাপ ১: GitHub Account খুলুন
1. [github.com](https://github.com) এ যান
2. Sign Up করুন (বিনামূল্যে)

### ধাপ ২: নতুন Repository তৈরি করুন
1. GitHub-এ Login করুন
2. উপরে **+** বাটনে ক্লিক করুন → **New repository**
3. Repository name দিন: `SojibTv`
4. **Public** রাখুন
5. **Create repository** ক্লিক করুন

### ধাপ ৩: ফাইলগুলো Upload করুন
1. Repository-তে **uploading an existing file** ক্লিক করুন
2. এই zip ফাইলের সব ফাইল/ফোল্ডার upload করুন
3. **Commit changes** ক্লিক করুন

### ধাপ ৪: APK Build হবে স্বয়ংক্রিয়ভাবে
1. **Actions** tab-এ যান
2. **Build Sojib Tv APK** workflow দেখতে পাবেন
3. Build শেষ হলে (৫-১০ মিনিট) ✅ চিহ্ন আসবে
4. **Artifacts** section থেকে APK download করুন!

## App Features
- ✅ Full Screen (Status bar ও Navigation bar লুকানো)
- ✅ Android TV Support
- ✅ Landscape mode
- ✅ Screen always on
- ✅ Back button কাজ করবে
- ✅ Offline error message (বাংলায়)
- ✅ Loading progress bar
